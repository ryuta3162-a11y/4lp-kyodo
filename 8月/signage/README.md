# 入口サイネージ動画（グラフィック版）

最新版: 2026年8月16日(日)まで・先着30名・3,740円版

デザイン共通：背景 `#C12632`・白文字＋黒縁・四角立体パネル  
出力：縦デザインを90°回転した 1920×1080（左傾け設置用）

## 生成

### 30秒・キャンペーン本編

```bash
cd 7月/signage
python generate.py
```

→ `joyfit-signage-30s.mp4`

| 秒数 | 内容 |
|------|------|
| 0〜3.5秒 | 夏得キャンペーン（8/16(日)まで・先着30名） |
| 3.5〜8.5秒 | キャンペーン特典（7月会費0円・7・8月オプション0円） |
| 8.5〜15秒 | キャンペーン特典（8〜1月・3,740円/月） |
| 15〜21.5秒 | ジム以外のサービス |
| 21.5〜30秒 | QRコード |

### 15秒・見学・体験無料

```bash
python generate_tour.py
```

→ `joyfit-signage-tour.mp4`

文言はフリートライアルLP（https://24-kyodo-freetrial.vercel.app/）を参照。

| 秒数 | 内容 |
