# 入口サイネージ動画（グラフィック版）

デザイン共通：背景 `#C12632`・白文字＋黒縁・四角立体パネル

## 生成

### 30秒・キャンペーン本編

```bash
cd 7月/signage
python generate.py
```

→ `joyfit-signage-30s.mp4`

| 秒数 | 内容 |
|------|------|
| 0〜4秒 | 夏得キャンペーン |
| 4〜11.5秒 | 価格（まだ間に合う / 3,630円） |
| 11.5〜18.5秒 | ジム以外のサービス |
| 18.5〜30秒 | QRコード |

### 15秒・見学・体験無料

```bash
python generate_tour.py
```

→ `joyfit-signage-tour.mp4`

文言はフリートライアルLP（https://24-kyodo-freetrial.vercel.app/）を参照。

| 秒数 | 内容 |
|------|------|
| 0〜7.5秒 | ジム無料見学・体験＋見学/体験/土足OK/60分 |
| 7.5〜15秒 | 入口インターホン＋スタッフ常駐時間（月木不在） |
