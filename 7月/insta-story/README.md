# インスタストーリー動画（10秒）

キャンペーン内容を **1080×1920（9:16）・10秒** のMP4にします。

## 生成方法

```bash
cd 7月/insta-story
python generate.py
```

→ `joyfit-story-10s.mp4` ができます（初回は `pip install pillow` が必要な場合あり）。

## 内容（10秒）

| 秒 | 表示 |
|----|------|
| 0〜2 | まだ間に合う！夏得キャンペーン！ |
| 2〜5 | 半年間お得・3,630円/月（7〜12月） |
| 5〜7 | 7月オプション0円 |
| 7〜9 | 7/12(日)まで・先着20名 |
| 9〜10 | 詳細はインスタ／プロフィールリンクから・店舗名 |

## インスタ投稿

1. スマホに `joyfit-story-10s.mp4` を転送
2. ストーリーに動画をアップロード
3. **リンクスタicker** で LP のURLを貼る（「詳細はリンクから」用）

## プレビュー

ブラウザで `index.html` を開くとアニメーションを確認できます。

キャンペーン文言が変わったら `generate.py` 内のテキストを更新して再生成してください。
